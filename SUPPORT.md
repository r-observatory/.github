# Support

Questions, bug reports, wrong numbers, missing packages, and feature requests all go to one place: [r-observatory/feedback](https://github.com/r-observatory/feedback/issues/new/choose).

For the project overview and links to every data channel, see the [R Observatory profile](https://github.com/r-observatory) and the site at [r-observatory.thecoatlessprofessor.com](https://r-observatory.thecoatlessprofessor.com/).

For private support requests, email [support@caffeinatedmath.com](mailto:support@caffeinatedmath.com).
