# Contributing to R Observatory

Thanks for your interest. R Observatory is a set of automated pipelines that publish data about CRAN and Bioconductor. Most repositories here are updated by scheduled jobs rather than by hand, so the most valuable contribution is often a good report rather than a pull request.

## One front door

All feedback about R Observatory, the site, the data, and the pipelines, is tracked in one place: [r-observatory/feedback](https://github.com/r-observatory/feedback/issues/new/choose). Use it to report a wrong number, a missing package, a bug, or to request a feature. Reporting there keeps everything discoverable and avoids scattering issues across repositories.

## Pull requests

Focused pull requests are welcome on the repository they affect. For anything larger than a small fix, please open a report at [r-observatory/feedback](https://github.com/r-observatory/feedback/issues/new/choose) first, so we can talk it through before you spend time on it.

## Code of conduct

Participation is covered by our [Code of Conduct](https://github.com/r-observatory/.github/blob/main/CODE_OF_CONDUCT.md).
