# Security Policy

R Observatory publishes public data about CRAN and Bioconductor. There is no private user data and no authentication, so most reports will concern the pipelines, the website, or the published database rather than a classic vulnerability. We still want to hear about anything that looks wrong or unsafe.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- Email [support@caffeinatedmath.com](mailto:support@caffeinatedmath.com).
- Or use GitHub's private "Report a vulnerability" button under the Security tab of the affected repository.

Include the affected repository, a description of the issue, and steps to reproduce it if you can. We will acknowledge your report as soon as we can and keep you posted on a fix. R Observatory is maintained by one person on a best-effort basis, so please allow time for a response.

For non-security bugs, wrong numbers, and missing packages, use [r-observatory/feedback](https://github.com/r-observatory/feedback/issues/new/choose) instead.
